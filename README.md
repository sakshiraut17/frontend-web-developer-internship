## 📂 Projects & Tasks Directory

### [Task 1: Transforming Wireframes into Static Web Pages](./task-1-wireframe-to-static/)
- **Objective:** Translate low/high-fidelity wireframe schematics into semantic, pixel-perfect static web pages.
- **Technologies:** Semantic HTML5, CSS3 Custom Properties, Flexbox & CSS Grid.
- **Key Deliverables:** `index.html`, `style.css`, `Task_1_Report.docx`.

### [Task 2: Implementation of Responsive Web Design](./task-2-responsive-web-design/)
- **Objective:** Build a multi-device adaptive interface across handheld phones, tablets, and wide monitors.
- **Technologies:** Mobile-first media queries, fluid typography (`clamp()`), CSS Grid `auto-fit/minmax`.
- **Key Deliverables:** `index.html`, `style.css`, `Task_2_Report.docx`.

### [Task 3: Integrating JavaScript for Interactive UX](./task-3-interactive-javascript/)
- **Objective:** Enhance user experience using vanilla JavaScript (DOM manipulation, event delegation, client-side validation).
- **Technologies:** Vanilla JavaScript (ES6+), LocalStorage persistence, modal accessibility, dark/light theme switching.
- **Key Deliverables:** `index.html`, `style.css`, `app.js`, `Task_3_Report.docx`.

### [Task 4: Enhancing Web Page Performance and Accessibility](./task-4-performance-accessibility/)
- **Objective:** Attain 100/100 Google Lighthouse scores across Performance, Accessibility, Best Practices, and SEO, adhering to WCAG 2.1 Level AAA.
- **Technologies:** Semantic landmarks, ARIA live regions, skip-link navigation, contrast ratio >16:1.
- **Key Deliverables:** `index.html`, `style.css`, `app.js`, `Task_4_Report.docx`.

### [Task 5: Developing a Single Page Application (SPA) Simulation](./task-5-spa-simulation/)
- **Objective:** Client-side SPA simulation featuring routing, dynamic template mounting, browser history management, and central state.
- **Technologies:** Client-side Hash Router, View lifecycle hooks, CSS animations, state management.
- **Key Deliverables:** `index.html`, `style.css`, `router.js`, `app.js`, `Task_5_Report.docx`.
