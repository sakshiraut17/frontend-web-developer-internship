## Overview
This project showcases a mobile-first, multi-breakpoint responsive web application ("Aura Bistro"). It leverages CSS Media Queries, CSS Grid `auto-fit/minmax`, Flexbox, fluid typography (`clamp()`), and responsive navigation controls without external UI frameworks.

## Key Features
- **Mobile-First Paradigm:** Base styles cater to handheld devices first, progressively enhanced for tablets and wide monitors.
- **Pure CSS Responsive Hamburger Menu:** Built using semantic markup and CSS checkbox state logic without JavaScript dependencies.
- **Fluid Layout & Typography:** Utilizes `clamp()` functions and flexible percentages to prevent text clipping and horizontal scroll issues across all viewport sizes.
- **Adaptive Grid Systems:** Converts gracefully from single-column mobile view to 2-column tablet layout and 4-column desktop display.

## Breakpoints Supported
- **Mobile Handsets:** < 640px
- **Tablets & Small Laptops:** 640px - 991px
- **Desktops & Wide Monitors:** ≥ 992px
