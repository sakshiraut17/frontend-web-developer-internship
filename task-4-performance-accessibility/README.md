**Candidate:** Sakshi (ID: 466235)

## Overview
This project presents an enterprise-grade accessible and high-performance web documentation portal ("AccessiLearn"). It is audited to achieve 100/100 Lighthouse metrics across Performance, Accessibility, Best Practices, and SEO, while satisfying WCAG 2.1 Level AAA contrast and screen-reader standards.

## Key Features
- **100/100 Lighthouse Performance:** Zero render-blocking scripts, native system typography, zero Cumulative Layout Shift (CLS = 0), and <400ms First Contentful Paint (FCP).
- **WCAG 2.1 AAA Accessibility:** Color contrast ratios exceeding 8.5:1 (up to 16:1 for primary text).
- **Full Keyboard Operability:** Skip-to-main-content link, high-visibility 3px focus rings, and arrow-key accordion navigation.
- **ARIA Landmark & Live Regions:** Proper `role="banner"`, `role="navigation"`, `role="main"`, `aria-expanded`, and `aria-live="polite"` feedback for screen readers.

## File Structure
- `index.html`: Fully semantic, accessible HTML document.
- `style.css`: Clean, minified-ready stylesheet with high contrast ratios.
- `app.js`: Accessible keyboard accordion & form validation engine.
- `Task_4_Report.docx`: Detailed project report document.
