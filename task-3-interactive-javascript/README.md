## Overview
This project delivers a responsive, feature-packed productivity application ("TaskPulse") engineered using clean, modular vanilla JavaScript (ES6+). It showcases real-time DOM manipulation, event listeners, form validation with dynamic error states, state persistence via localStorage, and interactive UI animations.

## Key Features
- **Dynamic DOM Manipulation:** Real-time creation, updating, and removal of task nodes.
- **Form Validation & Error Feedback:** Validates required title inputs (>3 characters) before committing records.
- **Interactive Filtering & Live Search:** Instant keyword searching and status tabs (All, Pending, Completed, High Priority).
- **Persistent State:** Saves user tasks and theme preferences into browser `localStorage`.
- **Accessible Modal Dialog:** Focus traps, escape key support, and backdrop click dismissal.
- **Theme Switcher:** Seamless light and dark mode toggling with persisted state.

## File Structure
- `index.html`: Application structure and modal markup.
- `style.css`: Modern interface styling with custom properties and theme tokens.
- `app.js`: Modular vanilla JavaScript code using an IIFE closure pattern.
- `Task_3_Report.docx`: Detailed project report document.
