# Task 1: Transforming Wireframes into Static Web Pages
**Candidate:** Sakshi (ID: 466235)  
**Internship:** Frontend Web Developer Internship - YuvaIntern  

## Overview
This project converts wireframe schematics into a semantic, pixel-perfect, static landing page ("ApexStudio"). Built strictly with semantic HTML5 and standards-compliant CSS3, the project demonstrates layout fidelity, visual hierarchy, modular styling, and clean frontend architecture.

## Key Features
- **Semantic HTML5:** Full usage of `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` elements.
- **CSS Architecture:** Organized around custom variables (design tokens), normalized resets, and modern Flexbox/Grid modules.
- **Visual Hierarchy:** Distinct type scales, elevated card surfaces, and wireframe representation mockups.
- **Zero Third-Party Dependencies:** Pure lightweight vanilla code ensuring blazing fast load times and clean structure.

## File Structure
- `index.html`: Core document structure with semantic markup.
- `style.css`: Clean, modular stylesheet containing custom properties and layout rules.
- `Task_1_Report.docx`: Detailed project report document.
